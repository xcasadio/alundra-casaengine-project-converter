submodule `a6efd2a9` (only the author's `CasaEngine.Launcher/Program.cs` is modified; not read). `chantier/audio-modern`

  to the report's `mg/` except the tool's version trailer.

## Corrections to carry
1. **Inspector test:** `CasaEngine.Editor` already exposes internals to `CasaEngine.Tests`. Make `CreatePreviewCopy`
   `internal` and test that it copies `LoopStartSample`, instead of leaving that silent-drop site untested.
2. **Seam buffers reduce the margin:** at every loop seam, a short end-of-data buffer occupies one of the 3 slots.
   Worst case ≈ 96 ms (track 6 under B), not 185.8 ms. Put this in the queue-depth decision. Optional design: fill
   across the seam so that buffers stay full.
3. **B2 red run:** never with `RecordSubmittedBuffers = true`, because the spinning thread would keep copying without
   bound. Assert submitted bytes instead.
4. **audio-modern has moved on** (`d2397514`): `AudioDemo.cs` +197, `audio-system.md` §9, §10 and §11 all edited, and
   `:256-257` rewritten. Expect bigger conflicts than stated. Its S3 also targets `WavStreamReader`/`MusicPlayer`
   (§10 text).
5. **Depth-24 test values:** with today's `SampleCount` the tests would read 16, then 14. The 22/24 values need
   `SampleCount ≥ (target+2)×4096`. Also update the cross-reference in `StereoVoiceMixer.cs:35`.
6. **Wording:** Audio is not the last component (`ComponentOrder.cs:24-43`), and L2 does not straddle the seam. The
   conclusions do not change.
7. **For L-b (not L-a):** `bgm.json` `LoopDetected` is true on all seven one-shot tracks (26, 36, 37, 38, 40, 42, 43).
   It cannot serve as `IsLooped`. The "plays once" information needs its own field, as the §1.2w sketch implies.
