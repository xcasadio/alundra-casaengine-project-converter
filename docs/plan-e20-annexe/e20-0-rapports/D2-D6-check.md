**Missed or worth carrying into the plan:**
1. A direction change restarts the binary animation from frame 0 and reloads `CurrentAttack` (`0x80038AE0-0x80038B10`, compares the direction slot with `+0x98`). E20.c1 must check that the DLL resets its clock the same way.
2. `ComputeNewHp` reads the attacker's attack at call time (`0x8003A3BC lw 0x1c8(TouchingEntity)`), and in the real game that is tick N+1. D2 calls it right after the hit pass.
3. Spark RNG draws happen only if the effect slot is non-null (`0x80039204 beqz t3`). D2's stub always returns a slot, so a full effect pool, which skips the draws and changes the random stream, is not covered.
4. The D2 random sets always seed `0x12345678`; the notes say "per set".
