# the independent model (hmodel.py) on every run: one line per rule; a rule holds when the model equals the oracle on every tick it applies to
== A1 (200 ticks)
   HOLDS      hit pass: ticks of every ordered pair equal scen.hit_model (2 pairs)
   HOLDS      boots level equals the model of the inventory on every row
   HOLDS      hero sheet responses 1..11 equal kmodel.model_sheet on every row
   HOLDS      hero HP per tick equals the model (damage rule, hazard cost and floor, regeneration)
   HOLDS      hero HpMax per tick equals the model
   HOLDS      hero +0x1CC per tick (0x77 on the hurt tick, then down by one, held by the tick gate)
   HOLDS      hurt animation 0x31 / 0x3A on the hurt tick (unchanged by the locked 0x20 entry)
   HOLDS      hurt direction (GetDirection of hero - toucher, or +0x8C + 0x10)
   HOLDS      draw list: hero in it iff (+0x1CC & 3) != 3 (and the count of the list)
   HOLDS      stats mirror: clamp(HpMax, 50), clamp(HP, HpMax), frozen by the tick gate
   HOLDS      regeneration counters 0x80126FE8/EC/F0 per tick
   HOLDS      tick gate [0x800DC4B8] & 0x48: +0x1C, position, TouchingEntity frozen
   HOLDS      hurt timeline 0x31 x4, 0x1C x11, Idle with the direction flipped (1 hurts checked)
   HOLDS      no unwritten-byte read during the run
