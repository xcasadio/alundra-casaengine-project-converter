## Method

`mutants/mut.py.txt` (the script, kept as text): for each mutant it checks that its anchor is found exactly once, rewrites the source file (line endings kept), runs
`dotnet test Alundra.Tests -c Release -p:CustomAfterMicrosoftCommonTargets=<skipcopy.targets> --filter <the tranche and its witnesses> --blame-hang-timeout 60s` in the foreground, restores the file with `git checkout -- <file>` and checks `git diff` of `Alundra` and `Alundra.Tests` is empty (printed `clean=True` after every mutant).
The filter selects 455 tests: `Ai.Objects.ChestAi*`, `ChestExportGuardTests`, `Items.MagicSeedTests`, `Items.ItemEffectsTests`, `ItemAndMoneyOpcodesTests`, `Ai.Objects.PickupAi*`, `SaveGames.TestSavesTests`, `Ai.NativeSpriteRegistryTests`, `Arcs.LiftArcTests`, `Arcs.LiftMap72ArcTests`, `Hero.LiftWorldTests` (baseline run on the unmutated tree: 455 of 455 green, 52 s). `mutants/<id>.killed.txt` lists the red tests of each mutant.
