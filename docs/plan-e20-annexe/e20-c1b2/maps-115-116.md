## 1. Conventions

- **Tick order** (`AlundraWorldProxy.cs:2283-2379`, `RunEntityBlock :2655-2729`). One logic tick runs these in order:
  - pad, dialogue box, then the map-events pass (`RunMapEventsPass :2887`);
  - hero `MovePlayer`, then `TickPrograms` of each entity in slot order (pick then run, `AlundraEntityScriptProxy.cs:1519-1637`);
  - pending triggers, then the counters pass (`:2741`, which clears `TouchingEntity` and `HitCounter` and decrements the `+0x1CC` and `+0x1D0` counters);
  - lists, animation clock, physics, and last the hit pass (`AlundraHitPass.cs:78`).
- **H** is the tick whose hit pass hits the lever. The sword press at tick k hits at k (H1-near of the c1a oracle: Square at tick 1, contact at tick 1).
  - The lever picks D at H+1 (`:1574-1578`). `TouchingEntity` is cleared by that tick's counters pass.
  - A B program sees a flag set by a C or D program one tick later, because the map-events pass runs first in the tick.
- **Flags.** The id is `v1 | v2<<8` and the mask is `1 << (v1 & 0x1F)` (`:581-595`). Bit 0x8000 selects the temporary bank (`AlundraGameState.cs:313-328`).
  - Temporary flags are cleared at every map entry (`:347-351`).
  - T1 = 0x8001 (bank word 0, bit 1), T2 = 0x8002 (word 0, bit 2), T101 = 0x8065 (word 3, bit 5), T102 = 0x8066 (word 3, bit 6).
  - G262 = 0x106 (word 8, bit 6), G569 = 0x239 (word 17, bit 25), G659 = 0x293 (word 20, bit 19).
  - Binary `0x8003DEFC` (0x32 toggle is a XOR), `0x8003DE6C` (0x31 jumps when the bit is CLEAR), `0x8003E35C` (0x36 passes when SET).
- **Jumps** are relative to the instruction address. Hand-checked from the binary: `0x8003DE6C` returns the signed 16-bit displacement (the DLL `FlagBranch` takes the displacement in the same way). Break (0x00) ends the call with pc+1. End (0xFF) does not advance pc, so it repeats every tick.
- **Animation end** (`0x1C`, `RepeatAnimation :2807`).
  - A Hold animation of L ticks started by `0x1A` at tick s makes `0x1C [1]` pass at **s+L+1**.
  - The data are the measured pins T-D1 (L=24 gives s+25) and T-D2 (Hold 32, count 3, gives s+99 = 3x33) in `docs/plan-e19-opcodes.md ~1968-1976`.
- **Pixels.** `PosX = (XPos*12+12)<<16` and `PosY = (YPos*8+8)<<16` (`EntityRecordMapper.cs:177-191`). `PosZ = Height<<19`, which is Height x 8 px (`:196-204`). Then `PosZ -= ModZ` (`AlundraEntitySpawnFactory.cs:671`), raised to the terrain only if `<=` it (`:676-683`).
  - Binary `0x8003A2B0-0x8003A2E0`: (XPos*3<<2)+12, (YPos<<3)+8, Height<<19.
  - Cell height unit is 16 px (`AlundraCellsCollisionField.cs:382-406`).
  - `TileX = (PosX>>16)/24`, `TileY = (PosY>>16)/16`, `TileZ = PosZ>>20`.
- **Body box.** Sprite 49 header: offset (-12,-8,0), size 24x16x16.
  - `ModX = -12<<16`, `Width = (24<<16)-1`. `Height` is the Y size and `Depth` the Z size (`AlundraEntitySpawnFactory.cs:715-730`).
  - Overlap is widened by one raw unit: `boxPos` in `(bodyPos - boxN, bodyPos + bodyN)` (`AlundraHitPass.cs:54-61`).
- **Directions.** South = 0, North = 0x10 (16), West = 0x08 (8), East = 0x18 (24). `AnimationTables.cs:20` and `:55-59`. The animation row (down, up, left, right) resolves unambiguously for all four (`:30-36`).
- **Slots** for trace matching: A=0, B=1, C=2, D=3, E=4, F=5.
